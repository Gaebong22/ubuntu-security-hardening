# 프로젝트 개요

## 목적

Ubuntu Server의 보안 상태를 진단하고 하드닝한 과정을 문서와 evidence로 정리한 프로젝트다. 위험 식별, 정책 설계, 설정 적용, 정상·차단 테스트와 로그 검증을 하나의 흐름으로 구성했다.

## 현재 범위

- SSH 공개키 인증과 인증 정책 강화
- UFW 최소 허용 방화벽 정책
- nginx HTTP 정상 접근 검증
- 미허용 TCP 포트 차단 및 로그 검증
- 변경 전후 evidence 관리
- 후속 Linux 보안 진단 자동화

## 수행 과정

1. 변경 전 상태와 복구 방법 확인
2. 기존 SSH 세션을 유지한 상태에서 설정 적용
3. 새 세션을 이용한 정상 접속 검증
4. 비밀번호 인증과 미허용 포트 차단 검증
5. 변경 전후 설정 및 로그 비교

## 현재 상태

SSH와 UFW 하드닝 및 관련 테스트를 완료했다. 변경 전후 설정, SSH 인증 로그, UFW 정책과 차단 로그를 `evidence/`에 정리했다. Mac과 Pixel의 일부 연결 성공 결과는 당시 작성한 PASS 요약이며, client 원시 출력이 없는 항목은 최종 보고서에 증거 범위의 한계로 기록했다.
